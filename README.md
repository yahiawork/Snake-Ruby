# Snake Neon (Ruby + Gosu)

**Graphical** Snake game with:
- Main Menu (Play / High Scores / Settings / Quit)
- Smooth neon UI (glow rectangles)
- Animated transitions (fade overlay)
- Settings JSON: `data/settings.json`
- Scores JSON "DB": `data/scores.json`

## Install
```bash
bundle install
```

## Run
```bash
ruby main.rb
```

## Controls
Menu: ↑ ↓ Enter, Esc
Game: Arrow keys / WASD, Esc (menu), R (restart), Enter (menu on game over)
